VAULT VENTURES — PROFESSIONAL DASHBOARD REFINEMENT

Founder Dashboard, Investor Dashboard, Profile and Discovery are already approved.

Do NOT modify those approved screens.

Now design/refine ONLY the Professional Dashboard.

==================================================
1. ROLE CONTEXT
==================================================

This is the PROFESSIONAL workspace.

The same user account may also have:

- Founder
- Investor

roles.

The Professional Dashboard must show ONLY Professional-specific information.

Do NOT mix Founder businesses or Investor portfolio information into this workspace.

The user can switch between selected roles using the existing global Role Switcher.

Admin is completely separate and must NOT appear in the normal Role Switcher.

==================================================
2. DASHBOARD PURPOSE
==================================================

The Professional Dashboard should immediately answer:

- What opportunities are relevant to my skills?
- Which startups match my profile?
- What applications are active?
- Which connections/deals need attention?
- What skills or profile information should I improve?
- What should I do next?

The experience should feel like a premium professional collaboration workspace.

NOT like a job-board dashboard.
NOT like social media.
NOT like a generic SaaS dashboard.

==================================================
3. PAGE HEADER
==================================================

Create a compact header:

Good morning, Alex

Professional workspace

Keep the existing global Role Switcher.

Do NOT create another role selector inside the page.

==================================================
4. KEY METRICS
==================================================

Create a compact metric row:

Active Applications
Active Deal Rooms
Profile Views
Average Match Score

Keep metrics compact.

Do NOT create oversized statistic cards.

==================================================
5. RECOMMENDED OPPORTUNITIES
==================================================

This should be the primary dashboard section.

Show recommended startups/projects based on:

- Skills
- Experience
- Industry
- Availability
- Relevant matching criteria

Each recommendation should contain:

Business
Industry
Stage
Required skills
Match Score
Why it matches
Primary action

Example:

NovaTech AI

FinTech · Seed

Looking for:
AI/ML · Product Strategy

91% Match

Why you're matched:
AI/ML + Product + FinTech experience

[View Opportunity]

AI-related information uses the existing cyan visual language.

==================================================
6. APPLICATIONS
==================================================

Create a compact "My Applications" section.

Each application should show:

Business
Role / contribution
Application date
Current status
Last activity
Next action

Statuses may include:

Submitted
Under Review
Accepted
Rejected
Withdrawn

Use restrained semantic status indicators.

Do not use oversized badges.

==================================================
7. ACTIVE DEAL ROOMS
==================================================

Show active Professional Deal Rooms.

Each row:

Business
Founder / participant
Current stage
Last activity
Next action

Example:

NovaTech AI × Alex Morgan

Interest Confirmed

Last activity:
3h ago

[Open Deal Room]

Do not make this look like a messaging inbox.

==================================================
8. SKILL MATCHING
==================================================

Create a compact skills/matching section.

Show:

Your strongest matching skills

AI/ML
Product Strategy
Data Analysis

Then:

Skill gaps / requested skills

Only show this where meaningful.

The purpose is to help the Professional understand WHY opportunities match.

==================================================

==================================================

"Respond to application"

"Continue Deal Room"
