VAULT VENTURES — PROFESSIONAL DASHBOARD

IMPORTANT:
Design/refine ONLY the Professional Dashboard.

The following are already approved and MUST NOT be redesigned:
- Profile
- Discovery
- Founder Dashboard
- Investor Dashboard
- Deal Room

==================================================
1. ROLE CONTEXT
==================================================

Vault Ventures uses ONE account that may contain:

Founder
Investor
Professional

The Professional Dashboard must show ONLY Professional workspace information.

The same user may switch between:

Founder Workspace
Investor Workspace
Professional Workspace

using the existing Role Switcher.

Do NOT create separate accounts.

Admin is completely separate and must never appear in this Role Switcher.

==================================================
2. PROFESSIONAL DASHBOARD PURPOSE
==================================================

The dashboard should immediately answer:

- What opportunities match my skills?
- What applications are active?
- Which startups need my attention?
- Which Deal Rooms are active?
- How strong is my profile?
- What should I do next?

This should feel like a premium professional collaboration workspace.

It must NOT feel like:

- a job board
- LinkedIn clone
- social media feed
- generic SaaS dashboard

==================================================
3. PAGE HEADER
==================================================

Use a compact page header:

Good morning, Alex

Professional workspace

Keep the existing global Role Switcher in the application shell.

Do NOT create another role selector inside the dashboard.

==================================================
4. KEY METRICS
==================================================

Create a compact metric row:

Active Applications
Active Deal Rooms
Profile Views
Average Match Score

Use compact information blocks.

Do NOT create oversized statistic cards.

==================================================
5. RECOMMENDED OPPORTUNITIES
==================================================

This is the primary section.

Title:

Recommended Opportunities

Show opportunities based on the Professional's:

- Skills
- Experience
- Industry experience
- Availability
- Relevant matching criteria

Each opportunity should show:

Business
Industry
Stage
Required skills
Match Score
Why it matches
Primary action

Example:

NovaTech AI

FinTech · Seed

Looking for:
AI/ML · Product Strategy

91% Match

Why you're matched:
AI/ML + Product + FinTech experience

[View Opportunity]

AI information must use the existing cyan visual language.
