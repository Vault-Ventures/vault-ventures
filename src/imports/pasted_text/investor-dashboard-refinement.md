VAULT VENTURES — INVESTOR DASHBOARD REFINEMENT

Founder Dashboard is now approved.
Profile and Discovery are also approved.

Do NOT modify those approved screens.

Now design/refine ONLY the Investor Dashboard.

==================================================
1. ROLE CONTEXT
==================================================

This is the INVESTOR workspace of Vault Ventures.

The same user account may also have:

- Founder
- Professional

roles.

However, the Investor Dashboard must show ONLY Investor-specific workspace information.

Do NOT mix Founder businesses, Founder metrics, or Professional activities into this dashboard.

The user can switch workspace using the existing global Role Switcher.

Admin is completely separate and must NOT appear in the normal Role Switcher.

==================================================
2. DASHBOARD PURPOSE
==================================================

The Investor Dashboard should immediately answer:

- What investment opportunities should I look at?
- Which startups are the strongest matches?
- What is happening with my saved opportunities?
- Which connections/deals need attention?
- What is my current simulated portfolio status?
- What should I do next?

The experience should feel like a professional investment workspace.

NOT a generic SaaS dashboard.

==================================================

==================================================

Create a compact header:

Good morning, Alex

Investor workspace

Keep the existing global Role Switcher.

Do NOT create a second role-switching system inside the page.

4. INVESTOR METRICS
==================================================

Create a compact metric row:
