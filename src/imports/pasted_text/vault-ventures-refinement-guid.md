REFINEMENT TASK — VAULT VENTURES PREMIUM WEB DESIGN

Do NOT rebuild the product from scratch.

Do NOT change the product functionality, information architecture, routes, user roles, workflows, or business rules.

Refine the existing Vault Ventures web design you have already generated.

The existing UI is directionally correct, but it still feels somewhat like an AI-generated SaaS dashboard in places.

Your goal is to elevate it to a genuinely premium, mature fintech / venture-capital / B2B SaaS product.

==================================================
1. KEEP THE EXISTING FOUNDATION
==================================================

Preserve:

- Vault Ventures brand
- Existing PRD-defined color system
- Existing typography system
- Existing navigation architecture
- Existing role structure
- Existing information architecture
- Existing PRD functionality
- Existing reusable components
- Existing responsive web strategy

Do not introduce a new visual language.

==================================================
2. REMOVE GENERIC AI-DASHBOARD FEEL
==================================================

Audit every screen and remove anything that feels like:

- Generic SaaS template
- Dribbble-style decoration
- Excessive cards
- Excessive rounded containers
- Excessive badges
- Decorative gradients
- Unnecessary icons
- Large empty spaces
- Repeated information
- Visual clutter
- Artificial "AI-looking" decoration

The product should feel designed by a senior fintech product-design team.

==================================================
3. IMPROVE INFORMATION HIERARCHY
==================================================

Make the hierarchy significantly stronger.

Primary information:
- strongest visual emphasis

Secondary information:
- clearly subordinate

Metadata:
- quiet and compact

Actions:
- obvious but restrained

Do not make every section visually compete for attention.

Use typography, spacing, alignment and borders to create hierarchy instead of adding more cards or colors.

==================================================
4. MAKE AUTHENTICATED SCREENS MORE DENSE
==================================================

Authenticated screens should feel like professional financial workspaces.

Prefer:

Tables
Dense lists
Compact panels
Structured rows
Inline metadata
Contextual sidebars
Small but meaningful cards

Avoid:

Huge dashboard cards
Oversized statistics
Large empty hero areas
Marketing-style spacing

Every section must justify its existence.

==================================================
5. IMPROVE THE APP SHELL
==================================================

Refine:

Sidebar
Topbar
Role switcher
Global search
Notifications
Profile menu
Active navigation state

The shell should feel extremely polished and stable.

Use subtle:

- border transitions
- active indicators
- spacing
- typography hierarchy

Avoid excessive glowing effects.

The sidebar should visually disappear into the product rather than dominate it.

==================================================
6. IMPROVE CARDS
==================================================

Cards should not all look identical.

Use three levels:

1. Surface
2. Raised surface
3. Border-only information block

Only use a card when grouping information genuinely improves comprehension.

Do not wrap every section inside a rounded rectangle.

Reduce unnecessary corner rounding.

Maintain the PRD radius system.

==================================================
7. IMPROVE DATA VISUALIZATION
==================================================

Charts and scores must look analytical and professional.

Avoid:

- rainbow charts
- excessive gradients
- decorative graphs
- oversized circular gauges

Use restrained visualization.

AI scores should feel like decision-support tools, not gamified scores.

Every score must remain explainable according to the PRD.

==================================================
8. IMPROVE AI VISUAL LANGUAGE
==================================================

Cyan should remain the visual language for AI-generated information.

However:

Do not make the whole interface cyan.

AI elements should be identifiable through subtle:

- cyan accent
- radial indicator
- factor bars
- labels
- explanatory affordances

The rest of the interface should remain neutral and professional.

==================================================
9. IMPROVE TRUST / VERIFICATION
==================================================

Verification should feel authoritative but restrained.

Gold is ONLY for:

- verification
- trust
- verified status

Do not use gold decoratively.

Verification badges should feel premium and credible rather than flashy.

==================================================
10. IMPROVE DISCOVERY
==================================================

Discovery must feel like a professional opportunity-analysis workspace.

Strengthen:

- filters
- search
- sorting
- result density
- comparison
- Match Score presentation

Keep:

Search Results

and

AI Suggestions

visually distinct.

Do not make Discovery look like a social feed.

==================================================
11. IMPROVE DEAL ROOM
==================================================

The Deal Room is one of the most important screens.

Make it feel like a serious transaction workspace.

Prioritize:

- lifecycle state
- participant trust
- documents
- negotiation
- milestones
- activity history

Avoid making the chat the visual center of the entire screen.

The Deal Room should feel closer to a professional transaction workspace than a messaging application.

==================================================
12. IMPROVE MARKETING PAGES
==================================================

Public pages may use more visual storytelling.

However:

Avoid generic AI landing-page patterns.

Do not use:

- gradient blobs
- stock handshake images
- excessive floating cards
- meaningless 3D graphics
- giant typography everywhere

Use sophisticated:

- data structures
- controlled disclosure
- vault-inspired visual motifs
- subtle geometric systems
- real product UI previews

The landing page should immediately communicate trust and product maturity.

==================================================
13. IMPROVE MICRO-DETAILS
==================================================

Review every:

- padding
- margin
- line height
- icon size
- border contrast
- text contrast
- button height
- table row height
- alignment
- label hierarchy
- hover state
- focus state
- disabled state

Eliminate small inconsistencies.

The difference between "good" and "premium" should be visible in the details.

==================================================
14. RESPONSIVE WEB QUALITY
==================================================

This is a responsive WEB PLATFORM.

Refine:

Desktop
Tablet
Mobile Web

Do not simply shrink desktop layouts.

Reflow information intelligently.

Preserve hierarchy.

Never hide important information simply because the viewport is smaller.

==================================================
15. DESIGN REVIEW
==================================================

After refinement, perform a complete visual audit.

For every major screen ask:

1. Does it feel premium?
2. Does it feel like fintech/B2B SaaS?
3. Is the information hierarchy obvious?
4. Is anything unnecessarily large?
5. Is anything unnecessarily decorative?
6. Are there too many cards?
7. Are colors carrying meaning?
8. Is the UI consistent with the PRD?
9. Does it feel cohesive across Founder, Investor, Professional and Admin?
10. Does anything look AI-generated or template-based?

If yes, refine it.

==================================================

==================================================

Do not aim for:

"Beautiful AI-generated dashboard."

Aim for:

"A real premium fintech/venture platform designed by an experienced product design team."

The final result must be:

Quietly premium
Dense
Precise
Trustworthy
Sophisticated
Professional
Consistent
Usable
Responsive
Implementation-ready

This is refinement of the existing design.

Do NOT introduce new product functionality.

Keep it as a premium responsive WEB PLATFORM.
